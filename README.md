# Editar texto selecionado

Extensão para SillyTavern com controles dentro de **Extensions** — sem botão flutuante de lápis.

## O que faz

- Ativa ou desativa a extensão com **Ativar extensão**.
- Captura um trecho selecionado numa mensagem do chat ou numa caixa de texto.
- Permite alterar o trecho manualmente e aplicar a edição.
- Pede uma sugestão ao modelo já ativo no SillyTavern; a sugestão aparece para revisão e só é aplicada quando você clicar em **Aplicar edição**.
- Apaga somente o trecho selecionado.

## Instalação

1. No SillyTavern, abra **Extensions → Install Extension**.
2. Cole o endereço do repositório:

   `https://github.com/yasminisismignac-blip/st-edita-texto`

3. Instale e recarregue a página.
4. Abra **Extensions** e procure **Editar texto selecionado**.

## Como usar

1. Selecione um trecho de uma mensagem ou de uma caixa de texto.
2. Abra as opções da extensão em **Extensions**.
3. Revise ou altere o conteúdo da caixa de texto.
4. Use **Aplicar edição**, **Sugerir com IA** ou **Apagar seleção**.

A extensão atualiza e salva mensagens do chat. Para evitar alterações ambíguas, em mensagens ela só edita quando encontra o trecho selecionado uma única vez no texto original. Seleções que não possam ser associadas com segurança ao texto original não são alteradas. A sugestão de IA nunca substitui a mensagem automaticamente.
